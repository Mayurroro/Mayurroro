# Hi, I'm Mayuresh

Computer Engineering student at **D. Y. Patil College of Engineering and Innovation**, Pune.
I build machine learning systems end to end — training the model, then wrapping it in
something someone else can actually use.

Currently focused on **multimodal deepfake detection** and **computer vision for agriculture**.

## What I work on

| Project | What it does | Stack |
| --- | --- | --- |
| [DeepFake Detection](https://github.com/Mayurroro/DeepFake) | Detects manipulated images *and* audio. Image branch uses EfficientNet-B4; audio branch is a CNN-LSTM over Mel-spectrograms. The two are fused with a gated mixture-of-experts layer, so the model weights each signal by how much it trusts it. | PyTorch, EfficientNet, OpenCV, Librosa, FastAPI, ONNX, Docker, Streamlit |
| [DeepCrop](https://github.com/Mayurroro/Crop-Disease-Detection) | Plant disease classifier trained on PlantVillage, with Grad-CAM heatmaps so you can see *which part of the leaf* the model is using, plus treatment recommendations and confidence scores. | PyTorch, CNN, Grad-CAM, OpenCV, Streamlit |
| [Book Market](https://github.com/Mayurroro/BookMarket) | Full-stack marketplace for buying and selling books. | Python, Flask, HTML/CSS, JavaScript, SQL |
| [Student Performance Classification](https://github.com/Mayurroro/Student-Performance-Classification) | Classifies student performance from academic and demographic features. | Python, scikit-learn, Pandas, Streamlit |
| [Spam Email Detection](https://github.com/Mayurroro/Spam-Email-detection) | Classifies email as spam or ham from message text. | Python, scikit-learn, Pandas, Streamlit |
